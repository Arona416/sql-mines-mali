# sql-mines-mali
SQL analysis of mining data using PostgreSQL
# 📊 SQL Project – Mines du Mali

## 🎯 Objectif

Analyser les données d’exploitation minière au Mali à l’aide de SQL.

## 🧱 Structure de la base

* Sites miniers
* Employés
* Productions
* Ventes

## 🛠️ Technologies

* PostgreSQL
* SQL
* VS Code

## 📈 Analyses réalisées

* Salaire moyen par site
* Production totale par site
* Revenu généré par site
* Top performances

## 🚀 Compétences démontrées

* Création de base de données
* Modélisation relationnelle
* Requêtes SQL avancées
* JOIN multi-tables
* Agrégations (SUM, AVG, COUNT)
